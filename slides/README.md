# Slides

This folder contains the Beamer source, speaker notes, and compiled PDFs for the project presentation.

- `lvit_full_report_slides.tex`: full report presentation source.
- `*_script.md`: speaker notes/scripts.
- `figures/`: figures used by the deck.
- `*.pdf`: compiled presentation files.

Build from this folder:

```powershell
xelatex -interaction=nonstopmode lvit_full_report_slides.tex
```
